# BLE config page

Web Bluetooth editor for status, comment, callsign and quick message, plus
RSSI/SNR and BME280 readings.

- Enable Bluetooth once on the device: `Bluetooth → Bluetooth` = ON
- Default PIN: `123456`
- Deploy to `https://aprs-lora.pizones.com/config/`
- Requires Chrome/Edge (Android/desktop); iOS Safari is not supported

Uses the F4LEK/EA2OY BLE config service:
`f4e40001-…` (RX `f4e40002-…`, TX `f4e40003-…`).
