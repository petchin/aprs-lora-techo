โหมด IGate / Digipeater

        
        
        
        

          T-Echo ไม่มี WiFi: IGate ต้องต่อ host ที่มีเน็ต (Raspberry Pi/PC/มือถือ) ผ่าน USB/BLE KISS
          แล้วให้ host รัน aprx/APRS-IS — อุปกรณ์ทำหน้าที่เป็น LoRa TNC
        

        

          Auto ใช้ “มี host ต่ออยู่” เป็นตัวแทนของ iGate; ถ้า host ต่อแต่เน็ตขาด อุปกรณ์ตรวจไม่ได้
          ให้เลือก Digi เปิดตลอดหากต้องการ guaranteed
        

      


      

        
ส่งข้อความ APRS

        

          
          
          
        

        
APRS message ต้องเป็น ASCII; การส่งต้องมี callsign/passcode ที่ถูกต้องตามเครือข่าย

      


      

        
Remote control และ Backup

        
        
        
ถ้าเปิด: ส่ง APRS message ไปที่ E23BMY-12 เนื้อหา reboot confirm จาก callsign ในรายการ เพื่อรีสตาร์ท
